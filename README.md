# とりあえず勇者

『あとでやる』を『とりあえずやる』に変える冒険

1分だけ手をつければ報酬がもらえる、作業サポートWebアプリ（授業「ソフトウェアクリエイション」後半の課題）。

- 公開URL：https://toriaezu-hero-nine.vercel.app/
- 仕様書：[docs/spec.md](docs/spec.md)
- 実装計画書：[docs/plan.md](docs/plan.md)

## できること（v0.1.0 / MVP）

- **クエストに挑戦：** やることを入力して「挑戦！」。1分たつと先制攻撃成功で報酬が確定し、そのまま追撃（最大2時間）
- **報酬の受け取り：** 帰還したら1行冒険日誌を書いて宝箱を開け、XPを獲得
- **クエストを予約：** 日付と、時刻または合図（例：お風呂から上がったら）を決めておく
- **クエスト一覧：** 過去のクエストから再挑戦・予約・ピン留め
- **焚き火：** ほかのユーザーのオンライン・挑戦中・最終オンラインをリアルタイム表示（クエスト名は隠せる）

## 動かし方

1. `.env.example` をコピーして `.env.local` を作り、Supabase の URL とキーを入れる
2. `npm install`
3. `npm run dev`

## 技術スタック
React + TypeScript（Vite） / Supabase / Vercel
