# 『とりあえず勇者』仕様書 v0.1（MVP版）

元の企画書（Geminiとの相談版）を、MVPで作る範囲に絞って整理したもの。
変更点は「元案からの変更」に理由つきでまとめている。

---

## 1. コンセプト

- **アプリ名：** とりあえず勇者（旧仮称：1分勇者）
- **キャッチフレーズ：** 「『あとでやる』を『とりあえずやる』に変える冒険」
- **ゲームの核：** ボスを倒さなくていい。1発殴るだけで経験値がもらえるRPG

着手前の心理的ハードルと、ひとりで作業するときの誘惑を減らす作業サポートWebアプリ。

### 設計の4原則（変更なし）
1. **作業興奮：** 完了ではなく「1分の着手」で報酬を確定させる。1分経過時に操作を求めない。
2. **無言のボディ・ダブリング：** チャットなし。焚き火の周りに「今いる人」と「ゴースト」を表示する。
3. **ペナルティゼロ：** レベルダウン・記録リセット・没収なし。スキップできる。
4. **良心に訴える：** よそ見検知はしない。1行日誌・応援・正直スライダーで嘘をつきにくくする。

---

## 2. MVPの範囲

MVPの目的は「主要な機能が動くことの確認」。見た目・演出・細部は後回し。

### MVPで作る
| # | 機能 | 内容 |
|---|------|------|
| 1 | ゲストログイン | Supabaseの匿名ログイン。初回に表示名だけ入力 |
| 2 | タスク | 追加・一覧・討伐完了・今日は見送る |
| 3 | 遠征タイマー | 1分だけ触る → 1分で先制攻撃成功 → 自動で追撃 → 手動帰還 / 2時間で自動帰還 |
| 4 | 帰還モーダル | 1行日誌（必須）、正直スライダー（自動帰還時）、報酬受け取り |
| 5 | 焚き火（同席） | 今作業中のユーザーを表示（名前・タスク名） |
| 6 | ゴースト | 前日の同じ時間帯に作業していた人を、区別できる形で表示 |
| 7 | 応援（薪） | 帰還時、同席していた人へ自動で薪を1本送る |
| 8 | ステータス | XP・レベル・ゴールド・受け取った薪の数を表示 |

### MVPでは作らない（後回し）
- 拠点強化（テント・装備・ペットの見た目）
- ご褒美交換所（現実のご褒美チケット）
- 冒険日誌・討伐図鑑の閲覧画面
- ドット絵・アニメーションなどの演出（MVPは文字と簡単な図形でよい）
- メール / Google認証（匿名ユーザーをあとから本登録に切り替える）
- フェーズ2・3の機能

## 3. 元案からの変更

| 変更 | 理由 |
|------|------|
| ゴーストは半透明＋「〇時間前」表示で、本物の同席者と区別する | 本物のように見せると、気づかれたときに「サクラだった」と信頼を失う。原則4（誠実さ）と矛盾するため |
| 報酬の大部分は「1分の着手」で確定し、時間による差は宝箱のランクだけにする | 時間に比例して報酬が増えると、短く正直に申告した人が損をし、ごまかす動機が生まれるため |
| `ghost_activities` テーブルは作らず、`work_sessions` から求める | 同じ情報を2か所に持つと、片方だけ更新し忘れる原因になるため |
| `users.level` は保存せず `xp` から計算する | 同上 |
| タスクに `skipped_on`（見送った日付）を追加 | 「今日は見送る」を表すため。日付が変われば自動で一覧に戻る（罰なし） |
| 報酬の計算はDB側の関数で行う | 画面側（ブラウザ）で計算すると、ゴールドを自由に書き換えられてしまうため |

## 4. 遠征タイマーの仕様

### 基本の考え方
タイマーは「1秒ごとに数える」のではなく、**開始時刻を保存して、表示のたびに `今 − 開始時刻` を計算する**。
スマホで画面を伏せてブラウザが止まっても、開いた瞬間に正しい経過時間が出る。

### 状態
| 状態 | 経過時間 | 画面 |
|------|---------|------|
| 出撃中 | 0:00〜0:59 | カウントアップ。焚き火に自分が座る |
| 追撃コンボ中 | 1:00〜1:59:59 | 1分到達時は静かに表示が変わるだけ（音・モーダルなし）。宝箱のランクが上がっていく |
| 帰還（手動） | 任意 | 「キャンプに帰還する」で帰還モーダル |
| 自動帰還 | 2:00:00 | 画面を開いたときに2時間を超えていたら、自動帰還モードの帰還モーダルを出す |

- 遠征中のセッションは1人1つまで。
- 1分未満で帰還した場合は「先制攻撃前」なので報酬なし（記録は残す）。罰ではなく、宝箱が出ていないだけ。

### 宝箱のランク（暫定値・あとで調整）
| 作業時間（申告後） | ランク |
|-----------|-------|
| 1分〜29分 | 木 |
| 30分〜59分 | 銀 |
| 60分〜 | 金 |

## 5. 帰還モーダルの仕様

1. **正直スライダー（自動帰還時のみ）**
   - 選択肢：`1〜15分` `30分` `1時間` `2時間そのまま`
   - 短く申告した場合は「誠実な冒険者ボーナス」として薪+1（ゴールドやXPは増やさない）
2. **1行日誌（必須・1〜50文字）**
   - 入力するまで「宝箱を開ける！」ボタンは押せない
3. **報酬**
   - 基本報酬（1分達成で確定）：XP・ゴールド
   - 宝箱のランクに応じたボーナス
   - 同席していた人へ薪を1本ずつ自動送信
4. タスクは「討伐完了」を押すまで一覧に残り、何度でも再出撃できる。

報酬の具体的な数値は `src/config/rewards.ts` にまとめ、あとで調整する。

## 6. データモデル

```
profiles（ユーザー情報。Supabaseの認証ユーザーと1対1）
  id (= auth.users.id), name, avatar_type, xp, gold, firewood, created_at, last_active_at

tasks（タスク定義）
  id, user_id, title, status ('active' | 'completed' | 'archived'),
  is_pinned, trigger_config (JSON, フェーズ2用), skipped_on (date),
  total_duration_sec, attack_count, last_attacked_at, created_at

work_sessions（1回ごとの遠征記録）
  id, user_id, task_id, started_at, ended_at (遠征中は空),
  recorded_duration_sec, declared_duration_sec, is_auto_returned,
  memo_log, reward_rarity, earned_xp, earned_gold

cheers（薪・応援の記録）
  id, from_user_id, to_user_id, session_id, created_at
```

- `real_rewards`（ご褒美チケット）と `camp_upgrades` はMVP後に追加する。
- ゴーストは `work_sessions` から「ちょうど24時間前の前後1時間に開始した、他人のセッション」を取り出して作る。
- 他人のデータは直接読めないようにし（RLS）、ゴースト用には「名前・アバター・タスク名・開始時刻」だけを返す関数を用意する。

## 7. 画面構成（MVP）

- **スマホ（縦）：** 上に焚き火エリア、下にタスクエリア。縦に並べる。
- **PC：** 左に焚き火、右にタスク。幅を狭くしても崩れないようにする。
- 主要ボタン（出撃・帰還）は画面下側の、親指が届く位置に置く。

### 注意点
Supabaseの匿名ログインには、同じIPアドレスからの回数制限（初期設定で1時間あたり30回）がある。
発表で大勢が同じ学内Wi-Fiから一斉にログインすると、上限に当たる可能性がある。ダッシュボードで変更できるので、発表前に確認する。
